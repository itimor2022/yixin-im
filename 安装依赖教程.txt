
================================================================================
                      源码安装与运行教程
================================================================================

  本项目包含三个部分：
    1. Flutter 客户端（iOS / Android / macOS / Windows / Web）
    2. 管理后台（Vue3 网页端）
    3. Go 后端服务

  下面按顺序讲，照着做就行。


--------------------------------------------------------------------------------
  一、环境准备（先装好这些）
--------------------------------------------------------------------------------

  1) Flutter SDK
     版本要求：3.2.0 或以上（不超过 4.0.0）
     下载地址：https://docs.flutter.dev/get-started/install
     装好后终端跑一下：
       flutter --version
       flutter doctor
     确保没有红色报错。

  2) Node.js
     版本要求：20.19.0 或以上
     下载地址：https://nodejs.org
     推荐用 LTS 版本。

  3) pnpm（Node 包管理器，比 npm 快）
     装好 Node 后，终端跑：
       npm install -g pnpm
     版本要求：8.8.0 或以上

  4) Go 语言
     版本要求：1.24 或以上
     下载地址：https://go.dev/dl
     装好后终端跑一下：
       go version

  5) Xcode（仅 macOS，跑 iOS / macOS 客户端用）
     从 App Store 安装最新版。
     装好后终端跑：
       sudo xcode-select --install
       sudo xcodebuild -license accept

  6) Android Studio（跑 Android 客户端用）
     下载地址：https://developer.android.com/studio
     装好后打开，把 Android SDK、命令行工具装上。
     然后终端跑 flutter doctor，看 Android 那一栏是不是绿的。

  7) CocoaPods（仅 macOS，iOS/macOS 依赖管理）
     终端跑：
       sudo gem install cocoapods


--------------------------------------------------------------------------------
  二、Flutter 客户端 —— 安装依赖 & 运行
--------------------------------------------------------------------------------

  打开终端，进入项目根目录（就是有 pubspec.yaml 的那个目录）。

  第一步：安装 Flutter 依赖

    flutter pub get

    这一步会根据 pubspec.yaml 和 pubspec.lock 下载所有 Dart 包。
    网络不好的话可能要等一会儿，耐心等就行。


  第二步（iOS）：安装 iOS 原生依赖

    cd ios
    pod install
    cd ..

    这一步会根据 Podfile.lock 下载 iOS 的原生库。
    如果报错说找不到 pod，先跑 sudo gem install cocoapods。


  第三步（macOS）：安装 macOS 原生依赖

    cd macos
    pod install
    cd ..


  第四步：运行项目

    跑 Android：
      flutter run                 （默认连接的设备）
      flutter run -d chrome       （Web 端）

    跑 iOS（需要 macOS + Xcode）：
      flutter run -d iphone       （真机，需先用 USB 线连手机）

    跑 macOS 桌面端：
      flutter run -d macos

    跑 Windows 桌面端：
      flutter run -d windows


  ★ 重要：修改后端地址

    打开这个文件：
      lib/core/services/api/api_client.dart

    找到 ApiConfig 类，里面有两组地址（开发环境和线上环境）：

      // 本地开发环境
      static const String serverUrl = 'http://192.168.10.47:8080';
      static const String wsUrl = 'ws://192.168.10.47:8080/api/v1/ws';

      // 线上环境
      // static const String serverUrl = 'https://imapi.yixin.com';
      // static const String wsUrl = 'wss://imapi.yixin.com/api/v1/ws';

    本地开发时：把 192.168.10.47 改成你自己电脑的局域网 IP（或 localhost）。
    上线时：把上面两行注释掉，把下面线上环境的两行取消注释，改成你的域名。


  ★ 打包 APK（Android 安装包）

    项目根目录下有个 build_apk.sh，直接跑：
      ./build_apk.sh
    打包完成后，APK 会自动复制到桌面，文件名是「锦绣汇IM.apk」。


  ★ 安装到 iPhone

    项目根目录下有个 install_ios.sh，直接跑：
      ./install_ios.sh
    首次需要先用 Xcode 打开 ios/Runner.xcworkspace，
    在 Signing & Capabilities 里选你的开发者团队。


--------------------------------------------------------------------------------
  三、管理后台（admin 目录）—— 安装依赖 & 运行
--------------------------------------------------------------------------------

  打开终端，进入 admin 目录：

    cd admin

  第一步：安装依赖

    pnpm install

    这一步会下载 node_modules，大概 400 多 MB，要等一会儿。
    如果你没有 pnpm，用 npm 也行：
      npm install


  第二步：配置后端地址

    开发环境：编辑 .env.development 文件
      VITE_API_PROXY_URL = http://你的后端IP:8080

    生产环境：编辑 .env.production 文件
      VITE_API_URL = https://你的后端域名/api/v1


  第三步：运行开发服务器

    pnpm dev

    浏览器会自动打开 http://localhost:3006


  第四步：打包生产版本（部署到服务器用）

    pnpm build

    打包产物在 admin/dist 目录，把这个目录的内容放到 Web 服务器就行。


--------------------------------------------------------------------------------
  四、Go 后端 —— 安装依赖 & 运行
--------------------------------------------------------------------------------

  后端需要三个数据库服务先跑起来：MySQL、MongoDB、Redis。
  可以用宝塔面板一键安装，也可以自己装 Docker 版。

  —— 4.1 数据库准备 ——

    MySQL：
      创建一个数据库（比如叫 gaoranim）
      导入初始化脚本：
        mysql -u 用户名 -p 数据库名 < backend/baota/init.sql

    MongoDB：
      创建一个数据库和用户
      注意：消息单独存在另一个库（数据库名_messages），
      需要给用户授权这个消息库的读写权限。
      具体操作看 backend/baota/README.md 里 MongoDB 那一节。

    Redis：
      装好就行，默认配置即可。


  —— 4.2 安装 Go 依赖 ——

    cd backend
    go mod download

    这一步会下载所有 Go 依赖包。
    国内网络可能比较慢，可以先设置代理：
      go env -w GOPROXY=https://goproxy.cn,direct


  —— 4.3 修改配置文件 ——

    编辑 backend/baota/config.yaml，按你的实际情况改：

    server:
      port: 8080
      base_url: "https://你的域名"

    mysql:
      host: localhost
      port: 3306
      user: 你的用户名
      password: 你的密码
      database: 你的数据库名

    mongodb:
      uri: mongodb://用户名:密码@localhost:27017/?authSource=数据库名
      database: 数据库名_messages

    redis:
      addr: localhost:6379
      password: ""

    jwt:
      secret: 改成一个随机字符串（终端跑 openssl rand -hex 32 生成一个）

    agora（声网，音视频通话用，后台配置）:
      enabled: false      
      app_id: ""
      app_certificate: ""


  —— 4.4 本地开发运行 ——

    cd backend
    go run ./cmd/server

    看到日志输出 listening on :8080 就是跑起来了。

    默认管理员账号：admin
    默认密码：123456
    登录后请立即改密码！


  —— 4.5 编译部署到服务器 ——

    后端目录下有编译脚本：
      cd backend
      ./build.sh

    编译出来的二进制文件在 backend/baota/server。
    这是 Linux amd64 的可执行文件，直接上传到服务器就能跑。

    完整部署包：
      ./build.sh -a
    会生成 deploy.zip，包含程序、配置、脚本、数据库文件，全套。

    上传到服务器后：
      chmod +x server start.sh stop.sh restart.sh
      ./start.sh     启动
      ./stop.sh      停止
      ./restart.sh   重启

    推荐配合 Nginx 反向代理 + SSL 使用，具体看 backend/baota/README.md。

--------------------------------------------------------------------------------
  六、常见问题
--------------------------------------------------------------------------------

  Q: flutter pub get 报错怎么办？
  A: 检查 Flutter 版本是否 >= 3.2.0。跑 flutter doctor 看哪里有问题。

  Q: pod install 报错？
  A: 先跑 sudo gem install cocoapods，然后 cd ios && pod repo update && pod install。

  Q: pnpm install 很慢？
  A: 可以换淘宝源：pnpm config set registry https://registry.npmmirror.com

  Q: go mod download 很慢？
  A: 设置 Go 代理：go env -w GOPROXY=https://goproxy.cn,direct

  Q: Android 打包报错 minSdk？
  A: 本项目 minSdk 是 30（Android 11+），确保你的 Android SDK 版本够新。

  Q: iOS 签名报错？
  A: 用 Xcode 打开 ios/Runner.xcworkspace，在 Signing 里选你的开发者 Team。

  Q: 后端连不上数据库？
  A: 检查 config.yaml 里的数据库地址、用户名、密码是否正确。
     MongoDB 注意 authSource 参数要跟数据库名一致。

  Q: WebSocket 连不上？
  A: 如果用了 Nginx 反向代理，确保配置了 WebSocket 支持（proxy_set_header Upgrade）。
     具体配置看 backend/baota/README.md。

  Q: 管理后台登录不上？
  A: 检查 .env.development 里的 VITE_API_PROXY_URL 是否指向了正确的后端地址。
