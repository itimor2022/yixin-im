# 通用IM TestFlight 更新日志

版本：`5.0.0 (45)`

## 本次更新

- 修复首次安装后首次启动可能停留在启动图的问题。
- 修复通话一方挂断后，另一方偶发继续响铃的问题。
- 优化连续拨打、挂断时的 CallKit、RTC 和通话状态清理，降低多次通话后闪退风险。
- 加强 iOS VoIP 来电兜底处理，避免异常推送未及时上报 CallKit 导致系统终止 App。
- 恢复 Shorebird 原生自动补丁检查，后续 Dart 代码修复可在下次启动时自动生效。

## 测试重点

1. 删除旧版后，从 TestFlight 安装本版本，确认首次打开能够正常离开启动图。
2. 两台设备连续拨打和挂断至少 20 轮，确认任意一方挂断后双方都立即结束通话和响铃。
3. 测试前台、后台、锁屏以及 App 被结束后的来电，确认系统来电界面正常显示。
4. 保持 App 联网运行，完全结束 App 后重新打开，确认 Shorebird 补丁可以自动下载并在下一次启动生效。
5. 回归登录、消息收发、图片/文件、通知、相机和相册权限。
