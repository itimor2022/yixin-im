# VIP 发布前回归清单

更新日期：2026-06-24

## 必测边界

- 免费用户创建群聊：必须被拒绝，提示开通 VIP。
- 免费用户创建频道：必须被拒绝，提示开通 SVIP。
- VIP 用户创建群聊：未达上限时允许，达到套餐群数量上限时拒绝。
- VIP 用户创建频道：必须被拒绝，提示开通 SVIP。
- SVIP 用户创建频道：未达上限时允许，达到频道数量上限时拒绝。
- 过期、冻结、取消的会员：必须按普通用户权益处理。
- 钱包余额不足购买会员：必须拒绝，App 给出充值入口。
- 钱包锁定购买会员：必须拒绝，并展示明确错误。
- 已有更高等级会员购买低等级套餐：必须拒绝，避免降级覆盖权益。

## 后台检查

- 套餐启用/停用后，App 只展示启用套餐。
- 修改套餐权益后，App 会员中心展示的建群、频道、人数、文件上限与后台一致。
- 手动开通、续期、冻结、解冻、取消会员后，会员用户列表状态和 App 会员状态一致。
- 订单列表能区分钱包购买和后台开通，金额、套餐、状态、时间正确。

## App 检查

- 会员中心能加载套餐、状态、钱包余额和购买记录。
- 余额不足时，购买失败提示必须带“去充值”入口。
- 创建群聊、创建频道触发 VIP 权限失败时，必须带“去开通”入口。
- 群资料、频道资料、成员列表、@ 人列表展示 VIP/SVIP 标识不遮挡昵称和角色。

## 支付闭环

- 当前 VIP 购买路径为钱包余额扣款。
- 如果上线微信/支付宝直接购买会员，发布前必须补齐商户参数校验、回调验签、重复回调幂等、订单补偿、退款和对账流程。
- 未完成微信/支付宝生产闭环前，不应在 App 中宣传“微信/支付宝直接开通会员”。

## 命令验证

- 后端：`cd backend && go test ./...`
- Flutter 静态检查：`flutter analyze`
- 本地 API：`docker compose up -d --build api`
- 模拟器：安装本地包后，用 `10.0.2.2:8080` 登录并验证会员中心、购买失败提示、创建群/频道权限提示。
