# 后台配置说明

> 更新时间：2026-05-06  
> 适用范围：管理后台 `admin`、客服后台 `admin-kf`

## 1. 后台体系说明

本项目后台分为两套：

- 管理后台 `admin`
  - 面向总管理员、运营管理员
  - 负责全局配置、内容治理、用户管理、钱包财务、热更新等
- 客服后台 `admin-kf`
  - 面向官方客服
  - 负责邀请码、欢迎语、邀请用户、个人资料等

## 2. 管理后台模块说明

### 2.1 控制台

控制台用于展示系统当前运行状态和业务概览，当前包括：

- 核心业务统计卡片
- 新增用户列表
- 在线用户列表
- 用户增长趋势图
- 快捷操作入口
- 服务器运行状态卡片

服务器运行状态卡片可查看：

- 当前服务时间
- 运行时长
- Go 版本
- 协程数量
- CPU 核数
- 内存与 Heap 占用
- 消息发送/同步/推送队列
- 延迟与死信数量
- MySQL、MongoDB、Redis 状态

### 2.2 用户管理

当前可进行：

- 用户查询
- 用户筛选
- 用户资料查看
- 用户状态调整
- 用户封禁/解封
- 强制下线

### 2.3 会话与消息管理

当前可进行：

- 会话列表查看
- 聊天详情查看
- 消息搜索
- 会话辅助审查

### 2.4 动态与内容治理

当前可进行：

- 动态列表管理
- 动态审核
- 动态隐藏/恢复/删除
- 话题管理
- 敏感词管理
- 举报处理

### 2.5 发现页运营

发现页支持后台配置入口卡片，当前可管理：

- 标题
- 图标
- 打开网址
- 排序
- 显示/隐藏

适用场景：

- 活动入口
- 外部落地页
- 下载页
- 客服跳转页
- 宣传页

### 2.6 官方客服与官方资源

当前支持配置：

- 官方客服账号
- 官方群组
- 官方频道

并可联动以下业务策略：

- 新用户自动添加官方客服
- 新用户自动加入官方群组
- 新用户自动订阅官方频道
- 开启邀请码归属策略后，邀请码注册用户只自动绑定对应客服

### 2.7 钱包与财务后台

当前支持：

- 钱包总览统计
- 用户钱包列表
- 单用户钱包详情
- 余额调整
- 交易流水查看
- 支付密码处理
- 钱包锁定/解锁
- 充值订单审核
- 提现审核
- 红包记录管理
- 转账记录管理
- 退款处理
- 会员套餐管理
- 会员用户管理
- 会员订单管理

### 2.8 广播与通话记录

当前支持：

- 系统广播发送
- 广播记录查看
- 广播清理
- 通话记录列表查看

### 2.9 热更新后台

当前支持：

- 补丁创建
- 补丁发布
- 补丁暂停
- 补丁回滚
- 平台与版本范围控制
- 灰度比例控制
- 是否强制更新控制

### 2.10 表情商店后台

当前支持：

- 表情包目录管理
- 上下架控制
- 客户端安装与收藏能力联动

## 3. 系统设置页说明

系统设置页是整个项目最核心的配置中心，建议按以下分组理解。

### 3.1 应用基础信息

- 系统名称
- 系统版本
- iOS 版本号
- Android 版本号

用途：

- 用于后台展示
- 用于客户端版本识别
- 用于升级策略配合

### 3.2 升级与发布控制

- 是否强制更新
- 更新下载地址
- 更新提示文案

用途：

- 控制客户端整包升级
- 配合热更新使用时作为外层升级兜底

### 3.3 注册与登录策略

- 是否允许注册
- 是否必须填写邀请码
- 邀请注册链接基础域名

用途：

- 控制新用户进入路径
- 生成邀请注册链接时优先使用配置域名

### 3.4 手机号与安全策略

- 是否全局强制绑定手机号
- 消息加密模式
- 消息撤回时限
- 同一 IP 发言频率限制
- 同一用户发言频率限制
- 心跳超时秒数

消息加密模式当前为三挡：

- 明文模式
- 兼容模式
- 严格加密模式

### 3.5 动态与内容策略

- 是否允许发布动态
- 动态是否需要审核

用途：

- 控制动态广场的开放程度
- 控制审核前置还是直接发布

### 3.6 新用户导流策略

- 新用户是否自动添加官方客服
- 邀请码注册用户是否只绑定邀请码所属客服
- 新用户是否自动加入官方群
- 新用户是否自动订阅官方频道

这部分直接决定新用户注册后的通讯录和官方资源注入逻辑。

### 3.7 群组与频道治理

- 是否只允许邀请自己的联系人进群
- 群人数上限
- 频道订阅人数上限

适用场景：

- 控制拉群权限
- 降低恶意拉人
- 做大群/大频道容量限制

### 3.8 自定义网站栏目

后台可配置客户端底部中间的网站栏目，配置项包括：

- 是否启用该栏目
- 栏目标题
- 栏目图标
- 打开的网址

生效位置：

- 移动端底部导航
- 桌面端侧边导航

使用建议：

- 标题尽量短
- 图标建议为透明背景正方形
- 网址尽量使用 HTTPS

### 3.9 上传限制

- 图片大小限制
- 视频大小限制
- 文件大小限制
- 语音大小限制

用途：

- 控制客户端上传体积
- 降低服务器存储与带宽压力

### 3.10 音视频配置

- 默认 RTC 服务：Agora 或 LiveKit
- Agora 开关、App ID、证书、Token 过期时间
- LiveKit 开关、Server URL、API Key、API Secret、Token 过期时间
- 新通话/会议按当前默认 RTC 服务创建，历史通话/会议保留各自的接口来源

### 3.11 推送配置

当前支持：

- iOS APNs
- Android FCM
- 华为 HMS
- 小米推送
- OPPO 推送

后台用于保存各通道参数，后端运行时会动态加载。

### 3.12 协议文档

- 用户协议
- 隐私政策

支持作用：

- 提供给客户端展示
- 便于统一修改，不必每次重新发版

### 3.13 钱包与外部服务配置

- 支付网关配置
- 短信网关配置

说明：

- 支付配置用于充值支付链路
- 短信配置用于验证码、绑定手机号等流程

## 4. 发现页配置说明

发现页配置与系统设置页中的自定义网站栏目不是同一个东西：

- 发现页配置
  - 是发现页里的入口卡片集合
  - 可以配置多个
- 自定义网站栏目
  - 是底部导航里的独立栏目
  - 当前是单独一个固定入口

这两个能力可以同时存在。

## 5. 客服后台说明

客服后台当前主要承担邀请码归属与欢迎接待能力。

### 5.1 登录

- 使用已配置为官方客服的账号登录

### 5.2 工作台

- 查看邀请码使用情况
- 查看邀请数据概览
- 查看自己的服务状态

### 5.3 我的邀请码

- 查看邀请码
- 复制邀请码

### 5.4 我的用户

- 查看通过自己邀请码注册并归属到自己的用户

### 5.5 欢迎语设置

- 设置新用户自动收到的欢迎语

### 5.6 个人中心

- 查看个人资料
- 绑定手机号
- 修改密码

## 6. 配置变更生效说明

后台配置生效范围大致分为三类：

### 6.1 即时生效

- 发现页入口调整
- 官方客服与官方群/频道配置
- 广播发送

### 6.2 重新拉取后生效

- 客户端系统设置
- 自定义网站栏目
- 动态发布/审核策略
- 上传大小限制

### 6.3 与运行时服务联动生效

- 推送配置
- 支付配置
- 短信配置
- 音视频配置

## 7. 后台使用建议

日常运营建议优先关注：

- 注册开关与邀请码策略
- 新用户导流策略
- 消息加密模式
- 钱包审核与支付配置
- 服务器运行状态
- 热更新补丁状态

这份文档适合给运营、管理后台开发、测试和部署人员共同使用。
