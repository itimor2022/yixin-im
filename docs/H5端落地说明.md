# H5 端落地说明

## 当前结论

本项目不建议继续把现有 Flutter Web 直接兼容成 H5。现有 Web 已经被代码明确当成桌面端布局使用，继续混写会把移动端兼容成本推高。

本次已新建独立目录：

- `h5/`

## 第一阶段已落下的内容

- 独立 `Vite + Vue 3 + Pinia + Vant` H5 工程
- 复用现有后端接口
  - `/app/settings`
  - `/auth/login`
  - `/auth/register`
  - `/user/me`
  - `/chat/list`
  - `/contact/list`
  - `/app/discovery`
- 移动端基础页面
  - 登录
  - 注册
  - 会话
  - 联系人
  - 发现
  - 我的

## 目录

- `h5/src/services`: 接口层
- `h5/src/stores`: 状态管理
- `h5/src/router`: 路由
- `h5/src/views`: 页面
- `h5/src/layouts`: H5 主框架
