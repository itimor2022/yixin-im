## P0 阻断级

目标：确认基础链路、真机安装、消息可靠性、通话二次拉起和后台恢复没有阻断问题。

- 后端 `/health`
- 两台真机在线、包已安装、前台可启动
- 消息突发发送、消息记录不突然消失
- 音视频通话多轮拉起、挂断、二次拉起
- App 后台、前台恢复后消息和通话入口可继续使用

失败处理：P0 任意 FAIL 必须优先修复，修复后重跑 P0。

## P1 核心功能

目标：模拟真实用户在 App 内快速切换和连续操作。

- 登录态、会话列表、私聊、群聊入口
- 消息持久化、返回列表再进入、杀进程恢复
- 常用写操作：发送文本、长按菜单、资料页、设置页、联系人页
- VIP/SVIP/普通用户展示样式在资料、列表、群成员场景的基础巡检

失败处理：核心消息、会话、资料错乱按 P0 处理；纯 UI 展示缺陷按 P1/P2 记录。

## P2 稳定性和压力

目标：发现快速操作、网络恢复、推送和随机点击导致的问题。

- 快速多轮消息收发
- 未读数、推送、消息列表一致性
- 断网、恢复、后台、前台切换
- Monkey 快速随机点击
- logcat 崩溃、ANR、Flutter Error、Android Runtime Error 检索

失败处理：崩溃、消息丢失、登录态丢失必须修复；偶发 UI 跳转异常记录复现路径。

## P3 发版体验

目标：确认真机安装包和用户体验符合交付标准。

- APK 存在、包名、版本号、签名、安装更新时间
- 首屏启动、权限弹窗、横竖屏、后台恢复
- 截图、logcat、前台 Activity 证据
- 应用名、图标、权限声明基础核查

失败处理：签名/包名/安装失败必须立即阻断；体验问题记录优先级。

## P4 最高权限破坏性状态流

目标：补齐之前未测的会改变账号、资产、成员关系的操作。

脚本会自动创建 `p3a_*`、`p3b_*`、`p3c_*` 隔离账号，并只给隔离账号注入余额和 SVIP 权限。

- 支付密码设置、错误密码拒绝、正确密码通过
- 私聊创建、消息发送、删除确认
- 拉黑、解除拉黑、状态校验
- 群创建、加成员、移除成员
- 红包发送、领取、余额变化
- 转账发送、接受、余额变化
- 转账发送、拒绝、退款
- 充值订单提交
- 提现申请、冻结余额
- 旧直充接口拒绝
- 退出登录、旧 token 失效
- 切换账号 token 隔离
- 管理后台登录、用户、会话、钱包、提现、充值、红包、转账、VIP、广播列表联动

失败处理：真实业务规则导致失败时先记录规则；接口契约错误修脚本；业务逻辑错误修后端或前端。

## P5 发布准备

目标：确认交付物、代码质量和可维护性风险。

- 中文乱码检查
- APK SHA256、大小、路径记录
- Flutter analyze
- 构建告警记录
- 最终报告和 JSON 归档

当前已知构建告警：Flutter 提示未来会弃用当前 Android Gradle Plugin `8.9.1`、Kotlin `2.1.0` 支持，后续应升级到 Flutter 建议版本。
