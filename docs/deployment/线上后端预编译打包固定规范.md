# 线上后端预编译打包固定规范

## 固定结论

以后所有线上后端更新包，必须使用本地预编译后端二进制包。

禁止在服务器上执行 Go 编译，禁止让服务器拉取 `golang:*` 构建镜像。

## 为什么固定这样做

线上服务器网络不稳定，拉取 `golang:1.24-alpine` 这类构建镜像容易超时，导致更新失败。

后端二进制在本地 Windows 机器交叉编译为 Linux amd64 后上传，服务器只负责运行，部署更稳定、包更小、失败点更少。

## 固定打包方式

本地编译后端：

```powershell
cd <PROJECT_ROOT>\backend
$env:GOOS='linux'
$env:GOARCH='amd64'
$env:CGO_ENABLED='0'
go build -trimpath -ldflags='-s -w' -o server ./cmd/server
```

更新包必须包含：

```text
backend/server
compose.bt.yaml
deploy.sh
docker/
admin-dist/
后端更新说明.md
```

更新包禁止包含：

```text
.env
.env.bt
.env.example
```

## 固定线上端口

宝塔反代使用：

```text
后台：admin -> 127.0.0.1:18083
接口：api   -> 127.0.0.1:18080
```

`compose.bt.yaml` 中必须使用：

```yaml
api:
  image: alpine:3.19
  command: ["/app/server"]
  ports:
    - "127.0.0.1:${API_PORT:-18080}:8080"
  volumes:
    - ./backend/server:/app/server:ro

admin:
  ports:
    - "127.0.0.1:${ADMIN_PORT:-18083}:80"
```

不得再使用：

```yaml
api:
  build:
    context: ./backend
```

## 固定服务器执行命令

上传压缩包到 `/www/wwwroot/api.example.com/` 后执行：

```bash
cd /www/wwwroot/api.example.com
unzip -o genericim-online-backend-prebuilt-*.zip
chmod +x deploy.sh backend/server
API_PORT=18080 ADMIN_PORT=18083 bash deploy.sh
```

## 固定验证命令

```bash
docker compose --env-file .env.bt -f compose.bt.yaml ps api
docker compose --env-file .env.bt -f compose.bt.yaml logs --tail=80 api
curl -fsS http://127.0.0.1:18080/health
```

## 交付命名规范

后端线上包统一命名：

```text
genericim-online-backend-prebuilt-YYYYMMDD-HHMMSS.zip
```

输出目录统一放到：

```text
<PROJECT_ROOT>\artifacts\online-backend-prebuilt-YYYYMMDD-HHMMSS\
```
