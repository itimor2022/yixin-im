# 客户完整源码交付打包计划（2026-07-30）

## 目标与当前状态

从当前 `main` 工作区生成可供客户部署和二次开发的源码快照。源码基线为当前
Git 提交，同时纳入工作区内尚未提交但属于项目的业务源码和测试源码。

本文档是本次打包与验收范围，只有 ZIP、文件清单和外部 SHA256 校验均通过后，
才视为本次源码包已整理完成。

## 纳入范围

- Flutter 多端客户端源码及测试。
- Go 后端、数据库迁移、服务配置模板及测试。
- 运营后台、客服后台和 H5 源码。
- Docker、宝塔、构建、运维和验收脚本。
- 项目资源、第三方源码依赖及中文交付文档。
- 当前工作区内的群聊性能、消息可靠性、媒体上传和部署相关业务改动。

## 排除范围

- `.git`、`.codex`、本机调试目录和 Git 历史。
- `node_modules`、`.dart_tool`、`.gocache`、`build`、`dist`、覆盖率和缓存目录。
- 真实 `.env`、账号密码、云密钥、推送配置、签名证书、SSL 私钥和本机配置。
- 数据库备份、用户上传、日志、崩溃文件和已编译发布文件。
- 历史交付包、APK、AAB、安装程序和其他压缩归档。
- 与项目无关的空临时文件。

## 验收标准

1. 必需交付文档和核心源码模块存在。
2. 中文 `SOURCE_DELIVERY_README.md` 随包交付。
3. 禁止文件、缓存目录、本机绝对路径和常见真实密钥特征均无命中。
4. `MANIFEST-SHA256.txt` 与解压目录逐文件一致。
5. ZIP 内条目无重复、无反斜杠路径、无清单外文件。
6. 外部 `.zip.sha256.txt` 与最终 ZIP 的 SHA256 一致。
7. 输出最终路径、体积、文件数量、源码基线和校验值；不把本地打包等同于线上部署。
