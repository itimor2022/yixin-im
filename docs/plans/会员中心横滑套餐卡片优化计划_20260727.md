# 会员中心横滑套餐卡片优化计划

## 目标

- 顶部会员卡支持横向滑动查看普通用户、VIP、SVIP及后台配置的其他套餐。
- 通过下一张卡片露出、页码圆点和滑动提示，让用户明确知道可以继续横滑。
- 滑动套餐时同步更新权益说明、底部价格和购买按钮。

## 实施

1. 使用后台 `VipPlan` 数据生成卡片，不写死套餐名称、价格和权益。
2. 当前会员状态作为第一张卡片，后续卡片按后台返回顺序展示。
3. 不同等级使用差异化渐变、图标、当前/推荐状态标识。
4. 当前等级不可降级的套餐允许查看，但不联动为可购买套餐。
5. 手机显示下一张卡片边缘，平板限制内容宽度；系统字体放大时不溢出。
6. 卡片入场和切换增加一次性流光、呼吸光晕与粒子闪点；拖动过程增加缩放、倾斜和纵向视差。
7. 权益区及底部价格使用淡入位移动画，并尊重系统“减少动画”设置。
8. 手机端顶部会员横幅与深色导航栏连成整体并铺满屏宽，不再通过露出半张卡片提示滑动。
9. 核心权益由四个细长竖卡改为 2×2 宽版信息块；保留并增强钻石、星点、流光等会员特效。

## 验证

- 覆盖普通用户、当前会员、多套餐、窄屏及滑动联动。
- 验证滑动后权益、价格、购买确认内容一致。
- 执行目标静态分析和 Android Debug 构建。
