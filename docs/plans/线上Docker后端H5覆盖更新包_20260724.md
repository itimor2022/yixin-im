# 线上 Docker 后端与 H5 覆盖更新包计划

日期：2026-07-24

## 目标

基于当前工作区生成一个可上传到线上服务器执行的 Docker 覆盖更新包，只更新：

- Go 后端/API Linux amd64 二进制
- Flutter Web/H5 静态文件

线上安装目录默认使用 `/www/wwwroot/api.example.com`。

## 明确排除

- 不覆盖管理后台 `admin-dist`
- 不覆盖客服后台 `kf-dist`
- 不变更现有业务数据
- 不覆盖线上 `.env.bt`
- 不删除数据库、上传文件或 Docker volume
- 不执行 `docker compose down -v`

## 更新保护

1. 执行前检查 `.env.bt`、`compose.bt.yaml`、Docker Compose 和依赖容器。
2. 覆盖前备份当前后端、H5、MySQL、MongoDB 和 Redis。
3. 仅复制包内 `payload/backend` 与 `payload/web-dist`。
4. 强制重建 API 容器并重启 H5 容器。
5. 校验 API `/health`、H5 首页、`main.dart.js` 响应及文件 SHA256。
6. 任一数据库备份失败时，在覆盖开始前终止。

## 构建与验收

- `go test ./...`
- Flutter Web release 构建
- H5 线上 API/WebSocket/bootstrap 地址检查
- Linux amd64 ELF 后端检查
- Shell `bash -n`
- ZIP 条目审计，确认只包含后端/API、H5 和更新脚本
- ZIP SHA256 与旁车校验文件一致

## 交付

交付目录：`release-archives/customer-release-20260724/docker-backend-h5-update/`

服务器执行入口：

```bash
sudo INSTALL_DIR=/www/wwwroot/api.example.com bash update-customer.sh
```
