# 联系人资料页与二维码自适应优化计划

## 目标

- 压缩联系人资料页顶部区域，减少头像、留白和操作区对首屏的占用。
- 二维码名片保持正方形并扩大有效展示宽度，改善当前卡片细长、比例失衡的问题。
- 兼容常见 Android 小屏、长屏、刘海/挖孔、安全区、横向窄屏、系统字体放大及平板宽屏。

## 实施范围

1. 联系人资料页
   - 根据可用宽高和文字缩放动态选择头像、间距、操作按钮尺寸。
   - 四个操作入口等宽布局，长文案单行省略，避免窄屏或大字体溢出。
   - 顶部背景高度跟随实际紧凑布局，不再固定占用 450 逻辑像素。
   - 名称区域限制在安全宽度内，徽章和状态不挤出屏幕。

2. 二维码名片页
   - 卡片宽度由屏幕可用宽度计算并设置手机/平板上限。
   - 二维码按卡片宽度和屏幕高度等比计算，始终使用 1:1 正方形约束。
   - 小屏和矮屏自动收紧头像、间距、字号；内容超出时允许完整滚动。
   - 保留 SafeArea，避免状态栏、刘海、底部手势条遮挡。

## 验证

- 执行 Dart 格式化与目标文件静态分析。
- 检查 320、360、393、432、480 逻辑宽度下的关键尺寸边界。
- 确认现有二维码分享、复制、扫码和资料页操作逻辑不变。
