# 客户完整源码交付打包计划（2026-07-28）

## 交付目标

从当前工作区生成可供客户部署和二次开发的完整源码快照，覆盖 Flutter 多端客户端、Go 后端、运营管理后台、客服后台、Docker/宝塔部署脚本、配置模板和项目文档。

本次以当前 `main` 工作区为准，基线提交为 `b1650e4`，并纳入当前尚未提交的业务源码修改。

## 纳入范围

- Flutter：Android、iOS、Web、Windows、macOS 客户端源码。
- Go：API、WebSocket、数据模型、迁移和测试源码。
- 前端：运营管理后台、客服后台及 H5 相关源码。
- 部署：Docker、宝塔、构建和运维脚本。
- 资源：项目所需图片、字体、表情资源和第三方源码依赖。
- 文档：架构、配置、安全、运维、版权和源码交付说明。

## 排除范围

- `.git`、本机 IDE 配置、Codex 调试目录和 Git 历史。
- `node_modules`、`.dart_tool`、`build`、`dist`、缓存和测试产物。
- 真实 `.env`、云厂商密钥、推送配置、签名证书和私钥。
- 数据库备份、用户上传、日志、崩溃文件和已编译发布文件。
- 历史交付包、APK、AAB、安装包及压缩归档。

## 执行与验收

1. 运行源码交付前置校验，检查必需文档、禁止文件和常见密钥特征。
2. 使用白名单打包脚本复制当前源码快照。
3. 为包内文件生成 `MANIFEST-SHA256.txt`。
4. 生成 ZIP，并检查 ZIP 路径、禁止文件、源码模块和清单一致性。
5. 输出 ZIP 的文件数量、体积、SHA256 和当前源码基线。

## 交付边界

源码包不包含生产环境账号、密码、域名证书和云服务凭据。客户部署时应基于示例配置生成独立密钥，并按 `SOURCE_DELIVERY.md`、`docs/CONFIGURATION.md` 和 `docs/OPERATIONS.md` 完成环境配置。
