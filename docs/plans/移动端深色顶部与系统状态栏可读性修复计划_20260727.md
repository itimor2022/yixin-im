# 移动端深色顶部与系统状态栏可读性修复计划

日期：2026-07-27

## 问题

钱包等页面在亮色主题下使用黑色、红色或深色自定义顶部，但仍继承全局亮色页面的深色状态栏图标，导致时间、网络、电量等信息与顶部背景融在一起。

## 修复范围

1. 统一提供“深色顶部使用浅色状态栏图标”的系统栏样式。
2. 排查钱包、转账、红包、扫码、媒体预览、通话等深色或彩色全屏页面。
3. 深色顶部使用白色状态栏图标；普通浅色页面继续使用深色状态栏图标。
4. 不改变页面业务逻辑、主题配色和路由结构。

## 验证

1. Flutter 定向静态检查与相关组件测试。
2. 构建本地接口 Android Release APK。
3. 真机验证钱包页面顶部时间、网络、电量图标清晰可见。
4. 抽查转账、红包及至少一个黑色媒体/扫码页面。
5. 返回普通浅色页面后，状态栏图标能够恢复为深色。

## 风险边界

- 系统状态栏由 Android/iOS 与 Flutter 路由共同控制，页面切换后必须确认样式恢复。
- 全屏视频等页面可能主动隐藏系统栏，本轮只保证系统栏显示时具有正确对比度。
- 不在本轮重做页面视觉设计，仅修复系统栏和顶部控件的可读性一致性。
