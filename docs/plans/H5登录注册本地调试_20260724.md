# H5 登录注册本地调试计划

日期：2026-07-24

## 目标

在本地 Docker 后端和真实 Chromium 浏览器中复现并修复 H5 登录、注册错误，然后重新生成线上覆盖更新包。

## 调试对象

- H5：`h5/` 下的 Vue/Vite 客户端
- 后端：当前工作区构建的 Docker API
- 本地 API：`http://127.0.0.1:8080/api/v1`
- 本地 H5：使用同源代理提供静态文件与 `/api/v1`

## 验证流程

1. 重建并启动当前工作区 Docker API。
2. 执行 `h5` 的 TypeScript 检查和生产构建。
3. 使用临时同源服务器启动 `h5/dist`，避免把 CORS 问题误判为登录注册逻辑问题。
4. 真实浏览器执行：
   - 打开登录页；
   - 跳转注册页；
   - 创建唯一测试账号；
   - 确认注册后进入会话页；
   - 清理浏览器会话并使用新账号重新登录；
   - 记录 API 状态、浏览器异常、控制台错误和截图。
5. 修复发现的问题并重复完整流程。
6. 将线上后端/H5更新包改为使用 `h5/dist`，重新构建和审计。

## 验收标准

- `npm run build` 通过；
- Docker API 健康；
- 注册接口成功且 H5 正确进入登录后页面；
- 同一账号退出后可重新登录；
- 浏览器无未处理运行时异常；
- 新更新包只含后端/API与 Flutter H5。
