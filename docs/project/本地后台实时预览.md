# 本地后台实时预览

## 开发时看这个地址

后台开发时固定打开：

```text
http://127.0.0.1:8082/
```

现在 `8082` 默认由 Vite 开发服务提供，修改 `admin/src` 后会自动热更新，不需要重新打 Docker 后台包。

启动命令：

```powershell
pwsh -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local-admin-dev.ps1
```

后台运行：

```powershell
pwsh -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local-admin-dev.ps1 -Background
```

这个脚本会自动：

- 启动本地 MySQL、MongoDB、Redis、API。
- 停掉占用 `8082` 的 `genericim-admin` 静态容器。
- 用 `http://127.0.0.1:8080` 作为 API 代理。
- 启动 Vite 热更新后台。

## 模拟线上静态包时再用这个

只有需要验证 Docker 静态后台包时，才执行：

```powershell
pwsh -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\rebuild-local-admin-static.ps1
```

这个脚本会重新构建 `genericim-admin` 镜像、重启容器，并写入：

```text
http://127.0.0.1:8082/build-info.json
```

如果 `8082` 已经被 Vite 开发服务占用，先关闭开发服务，再执行静态包重建。

## 推送配置页面

极光推送配置页：

```text
http://127.0.0.1:8082/#/system/push-config
```
