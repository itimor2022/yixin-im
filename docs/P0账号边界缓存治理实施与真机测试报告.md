# P0 账号边界缓存治理实施与真机测试报告

## 1. 结论

P0 前端账号边界和退出治理已经完成开发，并通过静态检查、完整 Flutter 测试、Release APK 构建及两台 Android 真机验证。

本轮已验证的核心结果：

- 普通退出会立即冻结旧账号运行态并清除凭证，但不删除本地聊天记录和 E2EE 私钥；
- Alice 退出后重新登录，同一聊天页仍可见退出前消息；
- 同一台设备从 Alice 切换到 Bob 后，设置页显示 Bob 身份，不残留 Alice 账号资料；
- 两台真机分别登录 Alice、Bob，双向聊天列表和消息详情均正常；
- 退出、重登和切号过程中没有发现 FATAL、ANR、IsarError 或 Flutter 崩溃日志。

## 2. 本轮实现范围

### 2.1 统一账号会话边界

- 新增 `AccountSessionCoordinator`、`AccountContext` 和 `accountEpoch`；
- 手动退出、Token 失效和强制下线统一进入同一退出流程；
- 退出开始时同步切断旧账号写入资格，远端清理失败不阻断本地退出；
- WebSocket、推送延迟任务、导航和异步请求均校验账号世代。

### 2.2 账号数据与缓存隔离

- 联系人 Isar 使用 `accountId + userId` 复合唯一边界；
- 聊天列表、消息、文件夹、钱包、VIP、设备数、隐私设置和动态状态依赖当前账号；
- 红包、转账、收藏、自定义表情、最近表情和通知声音等 SharedPreferences 缓存改为账号哈希键；
- 不再扫描或回退读取其他账号及无归属的旧缓存；
- 账号切换时旧请求即使晚返回，也不能覆盖新账号状态。

### 2.3 本地唯一数据与运行资源

- 离线消息携带所属 `accountId`，按账号持久化、冻结和恢复；
- 退出时清理聊天运行态、会议、录音、通话、推送待跳转和未读角标；
- 普通退出不清空 Isar、不清空全部 SharedPreferences、不删除 E2EE 安全存储；
- 账号删除只处理目标账号的账号级偏好，不使用全局 `prefs.clear()`。

## 7. 当前边界

- 本轮真机覆盖 Android；iOS、macOS、Windows 和 Web 共用本次 Dart 账号边界逻辑，但尚未在本轮逐平台执行真机/桌面回归；
- P1 的“清缓存、清本机账号数据、重置加密身份”三入口及中断恢复不属于本轮 P0；
- 完整历史消息恢复仍受服务端消息查询范围和保留期限约束；
- 新设备恢复旧 E2EE 消息仍需后端密钥备份或可信设备重新封装能力；
- 本次“退出后恢复”验证的是当前账号可见聊天恢复和前端不删除本地数据，不等于承诺任意时间、任意新设备恢复全部历史。
