# 客户端功能说明

> 更新时间：2026-05-06  
> 适用端：Android、iOS、Web、Windows

## 1. 客户端整体结构

客户端当前以 Flutter 为统一实现，主要分为以下业务区：

- 启动与鉴权
- 首页与会话
- 联系人
- 自定义网站栏目
- 发现
- 动态广场
- 钱包与会员
- 音视频通话与会议
- 我的与设置

底部主导航当前为：

- 会话
- 联系人
- 网站栏目
- 发现
- 设置

## 2. 页面入口与路由范围

当前路由已覆盖以下主要页面：

### 2.1 启动与账号

- `/`：启动页
- `/login`：登录
- `/register`：注册
- `/forgot-password`：找回密码
- `/bind-phone`：绑定手机号

### 2.2 聊天与资料

- `/chat/:chatId`：单聊/群聊聊天页
- `/channel/:channelId`：频道聊天页
- `/search`：消息搜索
- `/scan`：扫一扫
- `/search-users`：搜索用户
- `/user/:userId`：用户资料页
- `/group/edit/:chatId`：群编辑页
- `/group/:groupId/profile`：群资料页
- `/channel/:channelId/profile`：频道资料页

### 2.3 主导航

- `/home`：会话首页
- `/contacts`：联系人
- `/portal`：自定义网站栏目
- `/discover`：发现
- `/settings`：设置

### 2.4 钱包与会员

- `/membership`：会员页
- `/wallet`：钱包首页
- `/wallet/recharge`：充值
- `/wallet/payment-result`：支付结果
- `/wallet/withdraw`：提现
- `/wallet/transactions`：交易记录
- `/wallet/set-password`：设置支付密码

### 2.5 通话与会议

- `/call`：通话页
- `/meeting/:meetingId`：会议页

## 3. 账号与安全功能

### 3.1 登录注册

- 用户名密码登录
- 注册
- 忘记密码
- 短信验证码重置密码
- Token 刷新
- 退出登录

### 3.2 邀请码与注册策略

- 支持邀请码注册
- 后台可控制邀请码是否必填
- 注册页会根据后台下发配置自动切换“必填/选填”状态

### 3.3 手机号绑定

- 支持绑定手机号
- 支持短信验证码流程
- 后台开启强制绑定后，客户端会在全局业务流程中拦截校验

### 3.4 设备安全

- 设备锁验证
- 新设备登录验证
- 扫码登录桌面端
- 登录确认页
- 已登录设备列表
- 终止单个设备
- 终止其他全部设备

### 3.5 隐私与账号保护

- 黑名单
- 隐私设置
- 两步验证相关承载
- 设备锁开关

## 4. 会话与聊天功能

## 4.1 会话列表

- 展示单聊、群聊、频道会话
- 最新消息预览
- 未读数展示
- 会话置顶
- 静音状态
- 草稿与本地状态恢复
- 多端同步后的列表刷新

### 4.2 消息类型

- 文本
- 图片
- 视频
- 文件
- 语音
- 位置
- 红包
- 转账
- 系统类消息

### 4.3 消息操作

- 发送
- 撤回
- 删除
- 编辑
- 回复
- 转发
- 表情回应
- 收藏
- 搜索

### 4.4 阅后即焚

- 输入区支持开启阅后即焚
- 消息结构支持是否焚毁与焚毁秒数
- 已开启时会在输入区显示提示条
- 适用于文本、位置、语音等消息发送链路

### 4.5 收藏消息

- 长按消息后可加入收藏
- 支持取消收藏
- 提供独立收藏页查看
- 收藏页支持：
  - 文本复制
  - 位置打开
  - 删除收藏

### 4.6 位置消息

- 请求定位权限
- 获取当前位置
- 发送位置消息
- 会话中以地图卡片样式展示
- 会话列表预览显示为位置类型

### 4.7 语音与语音转文字

- 支持语音录制与发送
- 消息结构支持语音转文字结果承载
- 转写文本可在本地消息模型和消息服务中同步展示

### 4.8 消息加密适配

- 客户端支持根据后台下发策略切换消息模式
- 当前支持：
  - 明文
  - 兼容加密
  - 严格加密
- 已接入设备密钥注册与会话成员设备密钥拉取流程

### 4.9 多设备同步

已覆盖的多端同步场景包括：

- 已读同步
- 资料更新同步
- 会话隐藏/删除同步
- 表情回应同步
- 自己其他设备状态变化同步
