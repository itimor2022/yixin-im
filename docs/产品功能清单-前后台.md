# 通用 IM 功能清单（纯功能版）

## 一、客户端功能（IM App）

### 1）账号与安全

- **账号体系**：注册、登录、用户名校验、Token 刷新、退出登录、修改密码
- **快捷登录**：二维码创建、登录状态轮询、已登录设备确认
- **隐私保护**：隐私设置、黑名单、账号注销
- **终端安全**：设备列表、会话列表、下线其他设备/会话、单设备下线
- **手机能力**：绑定手机号、发送绑定验证码
- **推送能力**：推送 Token 上报/删除、推送偏好设置

### 2）即时通讯

- **会话类型**：单聊、群组、频道
- **会话管理**：创建、查看、编辑、删除、隐藏
- **群组治理**：成员增删、角色设置、入群审批、邀请链接入群、主动退群
- **会话操作**：置顶、静音、标记未读、清空聊天记录
- **群扩展**：群公告管理、消息置顶
- **消息能力**：发送、同步、撤回、删除、已读回执、编辑、转发、表情回应
- **消息检索**：会话内搜索、媒体/文件列表、媒体数量统计

### 3）联系人与社交

- **联系人管理**：联系人列表、添加、删除、备注
- **用户发现**：用户搜索、资料查看、共同群组查询
- **举报入口**：用户可直接提交举报

### 4）动态广场

- **内容发布**：发布、编辑、删除动态
- **互动能力**：点赞、取消点赞、评论
- **内容发现**：热门话题、动态搜索
- **个人中心**：我的动态、我的点赞、我的评论、收到点赞
- **内容屏蔽**：屏蔽单条动态、屏蔽某用户动态

### 5）音视频与实时

- **实时通信**：WebSocket 在线通信与状态同步
- **音视频通话**：发起、接听、拒绝、结束、取消、历史记录
- **链接预览**：消息中的 URL 自动预览

### 6）钱包与会员

- **钱包基础**：钱包信息、交易流水、钱包设置
- **支付安全**：支付密码设置/修改、支付密码校验
- **充值能力**：在线支付下单、支付订单查询、充值单提交、充值记录查询
- **红包能力**：发红包、抢红包、红包详情
- **转账能力**：发起转账、接收/拒收、转账详情
- **提现能力**：提现方式查询、提现申请
- **会员能力**：会员状态查询、套餐列表、会员购买

### 7）设置中心

- **账户设置**：会员、钱包、通知、隐私、数据与存储
- **应用设置**：聊天设置、设备管理
- **外观设置**：深浅色模式切换、系统跟随
- **国际化**：多语言切换（含国际化资源）
- **其他设置**：贴纸与表情、FAQ、关于页
- **协议入口**：用户协议、隐私政策

## 二、后台管理系统（Admin）

### 1）数据仪表盘

- **核心统计卡片**：关键业务指标概览
- **用户看板**：最新注册用户、在线用户
- **趋势分析**：用户增长趋势图
- **快捷入口**：高频模块直达（用户管理、会话管理等）
- **系统信息**：系统版本、后端状态、当前时间

### 2）用户管理

- **用户列表与统计**：用户信息查询与指标查看
- **资料与状态维护**：用户资料编辑、状态调整
- **风控动作**：封禁/解封、冻结/解冻、踢下线
- **账户处理**：重置用户密码

### 3）会话与消息管理

- **会话管理**：会话列表、群组列表、频道列表
- **详情查询**：会话详情与成员列表
- **治理动作**：封禁/解封、解散、删除、移除成员
- **消息检索**：管理端多条件消息搜索

### 4）动态与内容治理

- **动态管理**：列表、统计、状态审核、删除
- **话题管理**：新增、编辑、删除
- **违禁词管理**：单条新增、批量导入、编辑、删除
- **举报管理**：举报列表、统计、处理、删除

### 5）钱包与财务管理

- **钱包总览**：钱包维度核心统计
- **用户钱包**：余额调整、流水查看、支付密码重置/清除、钱包锁定
- **提现审核**：提现列表、统计、审核流转
- **充值审核**：充值订单查看与审核
- **红包管理**：红包记录、详情、退款处理
- **转账管理**：转账记录、详情、退款处理
- **配置管理**：钱包参数、支付网关、充值方式
- **会员管理**：套餐管理、授予会员、取消会员、订单管理、汇总统计

### 6）系统配置中心

- **基本信息**：系统名称、系统版本、iOS/Android 版本号
- **更新策略**：强制更新开关、更新链接、更新文案
- **注册与安全**：允许注册、邀请码注册、强制绑手机
- **广场策略**：动态发布开关、动态审核开关
- **新用户策略**：强制关注官方用户/加入官方群组/订阅官方频道
- **系统阈值**：群上限、频道上限、撤回时限、IP/用户限频、心跳超时
- **音视频配置**：Agora / LiveKit 双接口开关、默认 RTC 服务、密钥与 Token 过期时间
- **推送配置**：APNs 开关与参数
- **上传限制**：图片/视频/文件/语音大小限制
- **协议文档**：用户协议与隐私政策（支持 Markdown）
- **官方资源**：官方用户、官方群组、官方频道、发现页入口管理

### 7）运营能力

- **全局公告**：公告发送、公告列表、批量清理
- **官方客服后台**：客服登录、资料管理、欢迎语、邀请码、邀请关系、客服看板

### 8）权限与角色控制

- **管理员体系**：管理员登录、当前管理员信息、密码修改
- **角色分层**：超级管理员、管理员、演示管理员
- **写权限控制**：关键写操作需写权限角色，演示管理员仅查看
