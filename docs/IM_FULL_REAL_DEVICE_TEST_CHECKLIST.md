# IM 全量功能真机测试 Checklist

**测试功能点总数：400 项**

统计口径：共 20 个模块，每模块 20 项；每个 `IM-xxx` 编号代表一个独立功能点。

对于产品未规划支持的行业标准能力，不应直接删除测试项，应标记为 `N/A` 并记录产品依据。

执行状态建议：`未测 / 通过 / 失败 / 阻塞 / N/A`。

每项失败至少记录：设备型号、系统版本、App 版本、账号、网络、时间、操作步骤、实际结果、日志和截图/录屏。

## 01. 注册、登录与账号生命周期（20项）

- [ ] **IM-001 手机号注册**：输入合法手机号、验证码并设置密码；账号创建成功，自动登录或按设计进入登录页。
- [ ] **IM-002 邮箱注册**：输入合法邮箱并完成验证码验证；账号创建、邮箱绑定和欢迎流程正确。
- [ ] **IM-003 验证码错误**：输入错误验证码；明确提示错误，不创建账号，并限制连续暴力尝试。
- [ ] **IM-004 验证码过期**：验证码过期后提交；拒绝注册/登录，允许重新获取，不接受旧验证码。
- [ ] **IM-005 验证码重复使用**：成功使用验证码后再次提交；旧验证码不可重复使用。
- [ ] **IM-006 验证码发送频率**：连续点击获取验证码；按钮倒计时、防重复请求及服务端频控生效。
- [ ] **IM-007 密码边界验证**：测试最短、最长、空格、中文、特殊字符和弱密码；校验规则与提示一致。
- [ ] **IM-008 密码登录成功**：使用正确账号密码登录；进入正确账号，初始化数据无缺失。
- [ ] **IM-009 密码登录失败**：输入错误密码；提示准确，不泄露账号是否存在等敏感信息。
- [ ] **IM-010 连续登录失败保护**：连续输入错误密码；验证码、限流或临时锁定策略按设计触发。
- [ ] **IM-011 账号不存在**：使用未注册账号登录；提示和注册引导正确，不产生异常会话。
- [ ] **IM-012 退出登录**：主动退出后返回登录页；本地鉴权失效，返回键不能重新进入账号。
- [ ] **IM-013 退出后的推送隔离**：退出账号后由其他账号发送消息；本机不再收到旧账号通知或明文内容。
- [ ] **IM-014 注销账号**：完成二次确认及身份校验；账号进入注销流程，数据处理符合产品规则。
- [ ] **IM-015 注销冷静期撤销**：冷静期内重新登录并撤销注销；账号和关系数据恢复正确。
- [ ] **IM-016 已注销账号登录**：注销完成后再次登录；拒绝登录或进入重新注册流程，不恢复旧身份。
- [ ] **IM-017 封禁账号登录**：使用被封禁账号登录；明确展示原因、期限和申诉入口，不进入主界面。
- [ ] **IM-018 Token失效**：后台使访问令牌失效后继续操作；客户端刷新令牌或安全退出，不陷入请求循环。
- [ ] **IM-019 首次登录初始化**：新账号首次进入App；会话、联系人、权限引导和默认设置完整且不重复弹出。
- [ ] **IM-020 登录协议勾选**：未同意用户协议/隐私政策时登录；按法规及产品要求阻止或明确提示。

## 02. 多端登录、设备管理与在线状态（20项）

- [ ] **IM-021 同账号手机互踢**：手机A在线时在手机B登录；按策略踢下A或允许共存，并给出明确提示。
- [ ] **IM-022 手机与桌面端共存**：手机和PC同时登录；消息、已读、撤回和会话状态正确同步。
- [ ] **IM-023 手机与Web端共存**：登录Web后在手机操作；多端数据一致，不产生重复消息。
- [ ] **IM-024 多端同时发送**：两个在线端同时向同一会话发送消息；顺序、发送者身份和去重正确。
- [ ] **IM-025 被踢下线提示**：触发互踢后观察旧设备；立即停止收发并展示设备、时间或原因。
- [ ] **IM-026 被踢后重新登录**：旧设备点击重新登录；可正常认证，不残留失效连接或空白页。
- [ ] **IM-027 修改密码后的设备失效**：一端修改密码；其他端按安全策略退出或刷新认证。
- [ ] **IM-028 注销指定设备**：从设备管理页移除另一台设备；目标设备及时失效并停止推送。
- [ ] **IM-029 注销全部其他设备**：执行“一键下线其他设备”；当前设备保留，其他设备全部退出。
- [ ] **IM-030 设备列表准确性**：检查设备名称、平台、最近登录时间和位置；展示与实际一致。
- [ ] **IM-031 新设备登录提醒**：首次在新设备登录；原设备或安全消息收到准确提醒。
- [ ] **IM-032 在线状态更新**：联系人从离线变在线；状态在合理时间内更新且不频繁闪动。
- [ ] **IM-033 离线状态更新**：杀进程或退出登录；服务端在超时后将状态更新为离线。
- [ ] **IM-034 前台活跃状态**：App进入前台并产生操作；在线/最近活跃时间按策略更新。
- [ ] **IM-035 后台在线状态**：App切后台；在线状态、推送状态和隐身策略符合产品定义。
- [ ] **IM-036 隐身模式**：开启隐身后保持在线；他人不可看到实时在线，自己仍可正常收发。
- [ ] **IM-037 最近上线时间权限**：设置仅好友可见或不可见；不同关系账号看到的结果正确。
- [ ] **IM-038 在线状态多端合并**：一个端离线、另一个端在线；账号总体仍应按策略显示在线。
- [ ] **IM-039 长期离线重新上线**：设备离线数天后登录；离线消息和多端状态完整恢复。
- [ ] **IM-040 系统时间异常**：手动修改手机时间后登录和收发；服务端时间线不被本地错误时间破坏。

## 03. 个人资料、设置与数据隔离（20项）

- [ ] **IM-041 修改昵称**：输入合法昵称并保存；个人页、会话、群成员等关联位置及时更新。
- [ ] **IM-042 昵称边界**：测试空昵称、超长、换行、Emoji和特殊字符；限制和计数准确。
- [ ] **IM-043 修改头像**：拍照或从相册选择并裁剪；上传成功，各页面缩略图刷新。
- [ ] **IM-044 头像上传失败恢复**：上传中断网；保留旧头像，提示重试，不出现永久加载。
- [ ] **IM-045 修改个性签名**：输入中英文、Emoji和边界长度；保存、展示和换行正常。
- [ ] **IM-046 修改性别/生日等资料**：选择并保存；重新登录后数据不丢失。
- [ ] **IM-047 修改账号标识**：按规则修改用户名或IM号；唯一性校验及修改次数限制生效。
- [ ] **IM-048 重复账号标识**：设置已被占用的用户名；明确提示，不覆盖他人数据。
- [ ] **IM-049 二维码名片刷新**：修改资料后打开个人二维码；身份仍可识别，显示信息按设计更新。
- [ ] **IM-050 扫描个人二维码**：另一设备扫码；准确进入目标用户资料页，不串号。
- [ ] **IM-051 设置语言**：切换系统支持语言；界面文案、日期和通知语言正确，无混杂或截断。
- [ ] **IM-052 字体大小适配**：调整系统字体和App字号；关键按钮可见，列表不重叠。
- [ ] **IM-053 深色模式**：跟随系统及手动切换；文本、图标、弹窗和媒体页面对比度正常。
- [ ] **IM-054 清理缓存**：清理图片、视频等缓存；账号数据和必要消息不被误删。
- [ ] **IM-055 存储占用统计**：对比清理前后；统计与实际空间变化基本一致。
- [ ] **IM-056 自动下载设置**：分别配置移动网络/Wi-Fi媒体下载；实际行为遵循设置。
- [ ] **IM-057 聊天背景设置**：设置全局或单聊背景；重启后保留，文字可读性正常。
- [ ] **IM-058 配置云端同步**：另一设备登录；应同步的设置同步，本地专属设置不被错误覆盖。
- [ ] **IM-059 切换账号数据隔离**：账号A退出后登录账号B；头像、搜索、草稿、文件均不串号。
- [ ] **IM-060 敏感页面截屏策略**：在二维码、密钥或隐私页面截屏/录屏；行为符合安全设计。

## 04. 联系人、好友关系与通讯录（20项）

- [ ] **IM-061 精确账号搜索**：输入完整账号/手机号；返回正确用户且不泄露受保护信息。
- [ ] **IM-062 模糊用户搜索**：输入昵称关键字；分页、排序和隐私过滤正确。
- [ ] **IM-063 空搜索与特殊字符**：提交空格、Emoji、引号等；无崩溃、注入或异常结果。
- [ ] **IM-064 发送好友申请**：填写验证语并发送；双方状态和系统提示正确。
- [ ] **IM-065 重复好友申请**：连续申请同一用户；服务端去重，不生成大量重复通知。
- [ ] **IM-066 接受好友申请**：接收方同意；双方联系人列表出现，并可立即聊天。
- [ ] **IM-067 拒绝好友申请**：接收方拒绝；关系不建立，申请方反馈符合隐私策略。
- [ ] **IM-068 好友申请过期**：处理过期申请；提示过期并允许重新申请。
- [ ] **IM-069 双方同时申请**：A、B同时互发申请；只建立一条关系，不出现状态冲突。
- [ ] **IM-070 删除好友**：A删除B；联系人和权限按单向/双向删除规则变化。
- [ ] **IM-071 删除后发消息**：删除好友后继续发送；按陌生人消息或重新验证规则处理。
- [ ] **IM-072 加入黑名单**：拉黑联系人；其消息、通话和申请被正确拦截。
- [ ] **IM-073 解除黑名单**：移出黑名单；后续互动恢复，屏蔽期间消息按规则处理。
- [ ] **IM-074 黑名单列表同步**：另一设备查看及修改黑名单；各端结果一致。
- [ ] **IM-075 修改好友备注**：保存中文、Emoji及长备注；联系人和会话展示一致。
- [ ] **IM-076 联系人标签/分组**：新增、移动、删除标签；成员关系正确，不误删好友。
- [ ] **IM-077 通讯录匹配**：授权读取通讯录；正确匹配已注册联系人并保护原始号码。
- [ ] **IM-078 拒绝通讯录权限**：拒绝权限后进入匹配页；提供解释和设置入口，不崩溃。
- [ ] **IM-079 联系人列表排序**：检查中文、多音字、英文、数字和特殊符号；分组及索引合理。
- [ ] **IM-080 大量联系人加载**：账号拥有大量联系人；分页、滚动、搜索流畅且无重复遗漏。

## 05. 会话列表与会话管理（20项）

- [ ] **IM-081 新消息创建会话**：首次收到陌生人或好友消息；会话条目正确生成。
- [ ] **IM-082 会话排序**：多个会话先后收到消息；按最新有效消息时间排序。
- [ ] **IM-083 置顶会话**：置顶单聊；重启、多端登录后状态保持。
- [ ] **IM-084 多个置顶排序**：置顶多个会话并持续收消息；置顶区规则稳定。
- [ ] **IM-085 取消置顶**：取消后会话回归时间排序，不丢消息。
- [ ] **IM-086 会话免打扰**：开启后仍收取消息但无声音/振动；角标策略正确。
- [ ] **IM-087 标记未读**：已读会话手动标未读；未读点及总角标同步变化。
- [ ] **IM-088 标记已读**：手动清除未读；会话和系统角标同步归零。
- [ ] **IM-089 删除会话**：删除列表项；按设计仅删会话或同时清本地记录，联系人关系保留。
- [ ] **IM-090 删除会话后再收消息**：对方再次发送；会话重新创建，内容和未读数正确。
- [ ] **IM-091 会话草稿**：输入文字后退出；列表显示草稿，重新进入光标和文本正确。
- [ ] **IM-092 多端草稿策略**：一端保存草稿，另一端查看；按产品定义同步或保持本地隔离。
- [ ] **IM-093 @提醒展示**：群聊中被@后返回列表；显示“有人@我”等准确提示。
- [ ] **IM-094 撤回提示作为末条消息**：最后一条被撤回；会话摘要和时间显示合理。
- [ ] **IM-095 多媒体摘要**：最后一条分别为图片、语音、视频、文件；摘要类型正确。
- [ ] **IM-096 发送失败摘要**：末条消息发送失败；会话列表有明确失败标识。
- [ ] **IM-097 未读数上限**：制造大量未读；显示数字或“99+”符合设计且总数正确。
- [ ] **IM-098 会话头像和名称更新**：联系人改名/换头像；列表缓存及时刷新。
- [ ] **IM-099 会话列表冷启动恢复**：强杀后启动；列表快速恢复且随后与服务端正确校准。
- [ ] **IM-100 跨账号会话隔离**：切换账号；不短暂显示上一账号的会话和未读内容。

## 06. 单聊文本、输入与基础交互（20项）

- [ ] **IM-101 发送短文本**：输入单个字符并发送；发送成功，双方内容一致。
- [ ] **IM-102 发送长文本**：发送达到上限的长文本；完整展示、复制和展开收起正常。
- [ ] **IM-103 超长文本限制**：超过上限发送；明确提示或拆分，不能静默截断。
- [ ] **IM-104 多行文本**：输入多次换行及空行；发送后的换行格式保持。
- [ ] **IM-105 中英文混排**：发送中英文字母、数字和标点；编码与换行无异常。
- [ ] **IM-106 Emoji覆盖**：发送系统Emoji、肤色、性别、家庭组合及国旗；双方渲染正确。
- [ ] **IM-107 生僻字与扩展字符**：发送生僻汉字、藏文、阿拉伯文等；不乱码或丢字符。
- [ ] **IM-108 特殊符号文本**：发送尖括号、引号、反斜杠和脚本片段；按纯文本安全展示。
- [ ] **IM-109 纯空格文本**：尝试发送空格、换行或零宽字符；按规则拦截且无空白气泡。
- [ ] **IM-110 快速连续发送**：连续点击发送多条文本；不重复、不漏发，顺序稳定。
- [ ] **IM-111 双方同时发送**：A、B近乎同时发送；双方时间线顺序可解释且一致。
- [ ] **IM-112 输入法发送键**：分别使用键盘发送键和界面按钮；行为符合设置。
- [ ] **IM-113 输入法切换**：在中文、英文、语音输入法间切换；草稿不丢，布局不跳动。
- [ ] **IM-114 文字选择复制**：长按消息复制全部或部分文字；剪贴板内容准确。
- [ ] **IM-115 粘贴长文本**：从剪贴板粘贴大量文本；界面流畅，计数和发送规则正确。
- [ ] **IM-116 链接识别**：发送HTTP、HTTPS和带参数链接；识别范围准确且不吞标点。
- [ ] **IM-117 电话/邮箱识别**：发送号码和邮箱；点击行为合理，不误识普通数字。
- [ ] **IM-118 引用回复文本**：引用指定消息并回复；引用内容、发送者和定位正确。
- [ ] **IM-119 回复已撤回消息**：对方撤回被引用消息；引用区按规则变更且不崩溃。
- [ ] **IM-120 滚动中的新消息**：停留在历史位置时收到消息；不强制跳底，展示新消息提示。

## 07. 消息状态、顺序、回执与互动（20项）

- [ ] **IM-121 发送中状态**：弱网发送消息；先显示发送中，成功后自然切换。
- [ ] **IM-122 发送成功状态**：服务端确认后更新；不会长期停留在发送中。
- [ ] **IM-123 发送失败状态**：断网发送；显示明确失败状态并保留原内容。
- [ ] **IM-124 点击失败消息重试**：恢复网络后重试；仅生成一条有效消息。
- [ ] **IM-125 自动重试去重**：发送超时但服务端已入库；重连后客户端不得重复显示。
- [ ] **IM-126 已送达回执**：接收端在线并收到消息；发送端按设计更新为已送达。
- [ ] **IM-127 已读回执**：接收端打开会话并看到消息；发送端更新为已读。
- [ ] **IM-128 未实际曝光不已读**：接收端仅收到通知或停在会话顶部；不可误报已读。
- [ ] **IM-129 批量已读**：进入包含多条未读的会话；已读范围和未读分割线正确。
- [ ] **IM-130 已读回执关闭**：关闭回执后阅读消息；对方不可看到已读，其他功能正常。
- [ ] **IM-131 多端已读同步**：在PC阅读；手机未读数和分割线同步清除。
- [ ] **IM-132 消息时间戳**：跨分钟、跨天、跨年查看；时间分割和格式准确。
