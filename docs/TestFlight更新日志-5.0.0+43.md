# 通用IM TestFlight 更新日志

版本：`5.0.0 (43)`

## 本次更新

- 优化登录、退出登录和账号状态恢复流程。
- 优化聊天会话列表加载、历史消息恢复和冷启动体验。
- 改进网络切换、前后台切换后的连接恢复，降低消息延迟和重复显示问题。
- 新增并验证语言切换和浅色/深色主题设置的保存与恢复。
- 优化缓存清理流程，增加清晰的确认和完成提示。
- 修复部分设置弹窗显示异常及页面生命周期相关问题。
- 接入 Shorebird Dart 代码热更新能力，后续符合条件的代码修复可通过补丁更新，无需重新下载完整 App。

## 本次测试重点

请重点验证以下内容：

1. 登录、退出登录以及重新打开 App 后的登录状态。
2. 私聊消息发送、接收、历史消息和会话列表恢复。
3. App 切换到后台，再回到前台后是否能够继续正常收发消息。
4. 语言切换、主题切换和设置保存。
5. 在 TestFlight 安装 `5.0.0 (43)` 后，保持 App 联网运行一段时间，再完全关闭并重新打开，确认热更新补丁正常生效。

## 问题反馈

如果遇到问题，请在反馈中附上：

- 设备型号和 iOS 版本；
- 出现问题的操作步骤；
- 是否从后台返回或重新启动过 App；
- 截图或录屏，以及问题发生的大致时间。

感谢参与本次 TestFlight 测试。
