# 项目全功能详细说明

> 更新时间：2026-05-06  
> 适用范围：当前仓库已实现的 Flutter 客户端、Go 后端、管理后台 `admin`、客服后台 `admin-kf`

## 1. 项目组成

本项目是一套完整的即时通讯与运营管理系统，主要由以下部分组成：

- Flutter 客户端：统一覆盖 Android、iOS、Web、Windows，并预留 macOS 代码结构。
- Go 后端：负责认证、消息、联系人、群组频道、动态、钱包、推送、热更新、系统设置等核心业务。
- 管理后台 `admin`：面向总管理员/运营管理员，用于系统配置、内容审核、用户管理、钱包财务、热更新等。
- 客服后台 `admin-kf`：面向官方客服/邀请码归属客服，用于邀请码、欢迎语、邀请用户管理等。

## 2. 客户端功能总览

客户端底部主导航当前包含：

- 首页/会话
- 联系人
- 自定义网站栏目 `Portal`
- 发现
- 我的/设置

并通过路由扩展了聊天页、群资料、频道资料、扫一扫、搜索、钱包、会员、设备管理、绑定手机、忘记密码、注册等页面。

## 3. 客户端详细功能

### 3.1 账号、注册与安全

- 支持登录、注册、退出登录、忘记密码。
- 支持邀请码注册策略。
- 支持后台全局控制是否允许注册。
- 支持后台全局控制“注册是否必须填写邀请码”。
- 支持后台全局控制“是否强制绑定手机号”。
- 当开启强制绑定手机号后，客户端会在业务流程中统一校验，而不是只在提现时校验。
- 支持设备锁校验、两步验证、隐私设置。
- 支持扫码登录其他设备与设备确认页。
- 支持查看当前账号已登录设备，并支持：
  - 终止单个设备会话
