# 音视频 Agora / LiveKit 双接口切换说明

> 更新时间：2026-06-08  
> 适用范围：Go 后端、Flutter 客户端、H5、管理后台 `admin`

## 1. 总体方案

系统同时保留 Agora 和 LiveKit 两套 RTC 接口，由后台系统设置中的 `rtc_provider` 决定新发起的单聊通话和会议使用哪一个服务。

- `rtc_provider = agora`：使用 Agora App ID、证书和 Agora RTC Token。
- `rtc_provider = livekit`：使用 LiveKit Server URL、API Key、API Secret 和 LiveKit Join Token。
- 已创建的通话/会议会记录自己的 `rtc_provider`，切换后台默认值不会强行改变正在进行或历史记录中的 RTC 服务。

## 2. 后台配置项

系统设置表使用以下 key：

| key | 说明 |
| --- | --- |
| `rtc_provider` | 当前默认 RTC 服务，值为 `agora` 或 `livekit` |
| `agora_enabled` | 是否启用 Agora |
| `agora_app_id` | Agora App ID |
| `agora_app_certificate` | Agora App Certificate |
| `agora_token_expire` | Agora Token 过期秒数 |
| `livekit_enabled` | 是否启用 LiveKit |
| `livekit_server_url` | LiveKit 服务地址，例如 `wss://livekit.example.com` |
| `livekit_api_key` | LiveKit API Key |
| `livekit_api_secret` | LiveKit API Secret |
| `livekit_token_expire` | LiveKit Token 过期秒数 |

`backend/config.yaml` 也保留 Agora / LiveKit 启动默认值；管理后台保存后的系统设置会覆盖启动配置。

## 3. 接口返回字段

客户端需要优先读取 `rtc_provider`，兼容读取 `provider`：

| 字段 | Agora | LiveKit |
| --- | --- | --- |
| `provider` / `rtc_provider` | `agora` | `livekit` |
| `channel_name` | Agora channel | 兼容字段，同 room |
| `room_name` | 兼容字段，同 channel | LiveKit room |
| `token` | Agora RTC Token | LiveKit Join Token |
| `app_id` | Agora App ID | 无 |
| `agora_uid` | Agora 数字 UID | 无 |
| `server_url` | 无 | LiveKit Server URL |
| `identity` | 用户 UUID | 用户 UUID |

后台通话记录列表和详情也会返回 `provider`、`rtc_provider`、`room_name`，便于排查某条通话实际走的是哪套 RTC。

## 4. 切换流程

1. 在管理后台系统设置中同时填写 Agora 和 LiveKit 配置。
2. 先保持 `rtc_provider = agora`，验证单聊语音、单聊视频、会议创建/加入正常。
3. 切换为 `rtc_provider = livekit`，保存设置。
4. 重新发起通话或会议，客户端应使用 LiveKit 连接；旧通话记录仍保留原 provider。
5. 若 LiveKit 临时不可用，可切回 `agora`，无需删除 LiveKit 配置。

## 5. 验收清单

- 管理后台保存 `rtc_provider` 时，只允许 `agora` 或 `livekit`。
- 切到 LiveKit 后，新通话/会议接口返回 `rtc_provider = livekit`、`server_url`、`room_name`、`identity`。
- H5、Flutter 发起和接听来电时都能按 `rtc_provider` 选择 SDK。
- WebPush 来电跳转 URL 带上 `room_name`、`provider`、`rtc_provider`。
- 后台通话记录能显示 Agora / LiveKit 接口来源。
- 切回 Agora 后，新通话/会议继续返回 Agora 字段，LiveKit 历史记录不被覆盖。
