## 一、项目说明

本次开发在现有通用 IM 系统基础上，对管理后台、Go 服务端、Flutter 会员端、内部端及 Windows 电脑端进行联合升级。

双方确认的最终范围共19项，其中：

- 8项属于现有功能复核或问题修复，随本次版本统一处理，不重复收费；
- 11项属于新增定制开发功能，按本计划报价、排期和验收；
- 原始反馈中的重复项目已经合并，不重复计算工作量和费用。

### 1.1 名词说明

- **会员端**：普通会员使用的 App 或相关下载页面；
- **内部端**：内部客服、运营、管理人员使用的业务端；
- **内部端口账号**：能够登录内部端的客服、运营或管理账号；
- **渠道来源**：会员通过指定下载域名和下载链接进入系统后形成的来源记录。

### 1.2 实施原则

- 所有业务数据存储在客户自己的服务器和数据库中；
- 渠道统计和 IP 归属地解析不调用第三方在线统计接口；
- IP 归属地使用服务器本地 IP 地址库解析，地址库支持人工更新；
- 权限控制同时覆盖客户端入口和服务端接口，不能只隐藏按钮；
- 管理员操作、批量撤回和重要配置修改保留审计记录；
- 升级过程不主动删除现有用户、好友、群组、消息和资金记录；
- 本计划只对11项新增定制功能计费，现有问题不重复收费。

## 三、多域名下载渠道及会员来源统计专项方案

### 3.1 域名与渠道码

- 会员端配置多条不同域名的下载链接；
- 每个下载域名对应一个唯一渠道码；
- 系统根据会员实际访问的下载域名自动识别渠道，不要求会员手工填写渠道码；
- 下载域名、渠道码和归因数据由后台维护，普通会员不能自行修改；
- 无法匹配已配置域名的访问记录为“自然来源”或“未知来源”。

示例：

| 下载域名 | 渠道码 | 下载链接 |
| --- | --- | --- |
| `download-a.example.com` | `CHANNEL_A` | `https://download-a.example.com/app` |
| `download-b.example.com` | `CHANNEL_B` | `https://download-b.example.com/app` |
| `download-c.example.com` | `CHANNEL_C` | `https://download-c.example.com/app` |

以上域名仅为格式示例，正式开发以客户提供的域名清单为准。

### 3.2 数据采集与用户绑定

会员访问或请求下载时，服务器记录以下信息：

1. 下载域名；
2. 渠道码；
3. 完整下载链接；
4. 访问 IP；
5. IP 归属地；
6. 访问或下载时间；
7. 访问编号或渠道凭证；
8. 注册或登录后绑定的用户 ID。

会员完成注册、登录或首次有效激活后，系统将用户 ID 与对应渠道记录绑定。默认采用“首次有效渠道”作为会员来源，避免会员后续重复打开其他链接覆盖原始来源；如客户要求采用“最后有效渠道”，应在开发启动前书面确认。

### 3.3 下载量与会员数统计口径

- **访问人数**：到达指定下载域名或下载页面的独立访问数量；
- **下载次数**：服务器收到的有效下载请求数量；
- **绑定会员数**：下载后完成注册、登录或首次有效激活，并成功绑定用户 ID 的会员数量；
- **实际安装成功数**：以客户端首次启动并成功回传为准，仅收到下载请求不能直接等同于安装成功。

### 3.4 内部端查询与展示

所有内部端口账号均可查看会员端渠道来源，不需要为单个内部账号重复授权。系统支持按照以下条件单独或组合查询：

- 下载域名；
- 渠道码；
- 用户 ID；
- 访问 IP；
- 完整下载链接；
- 时间范围。

内部端打开会员资料或私聊时，可显示类似以下信息：

```text
用户账号：customer_001    用户ID：8f3a****
渠道码：CHANNEL_A
下载域名：download-a.example.com
下载链接：https://download-a.example.com/app
下载IP：113.***.***.26    归属地：中国·广东·深圳
下载时间：2026-07-18 10:30:25
```

以上内容属于内部业务资料，不作为聊天消息发送给会员。普通会员、群成员及外部账号不能读取其他会员的渠道来源信息。

### 3.5 本地化实现

- 渠道映射、访问记录、用户绑定和查询统计均部署在客户自己的服务器；
- IP 归属地通过服务器本地 IP 地址库解析，不调用第三方在线 IP 查询接口；
- 下载域名由客户提供并完成域名解析、HTTPS证书和服务器接入；
- 渠道统计功能不依赖第三方统计平台，客户可自行掌握原始数据。

## 五、整体验收标准

### 5.1 权限与安全

- 普通成员不能使用群主或管理员功能；
- 后台关闭好友、附近人、文件、红包和转账后，旧客户端直接调用接口也不能绕过；
- 音视频呼叫权限由服务端最终判断；
- 所有内部端口账号可查看会员渠道来源，普通会员端不能读取内部来源数据；
- 管理员创建账号、批量撤回和清空群消息保留操作记录。

### 5.2 多账号隔离

- 账号A和账号B的头像、用户名、用户 ID、聊天、联系人、草稿和未读数互不混用；
- 切换账号后，旧账号异步请求不能覆盖当前账号数据；
- 退出一个账号不删除其他已保存账号；
- Android和Windows至少各完成一轮多账号切换验证。

### 5.3 渠道来源统计

- 每个下载域名能够准确映射唯一渠道码；
- 访问 IP、IP 归属地、用户 ID、下载域名、下载链接和时间记录完整；
- 注册、登录或首次有效激活后可以绑定会员用户 ID；
- 内部端支持按域名、渠道码、用户 ID、IP、链接和时间查询；
- 各下载链接的访问量、下载量和绑定会员数可分别统计；
- 普通会员端无法越权读取渠道来源数据；
- 渠道查询与 IP 解析不依赖第三方在线统计接口。

### 5.4 兼容与稳定性

- 数据库升级不删除原有用户、好友、群组、消息和资金记录；
- 关闭红包或转账后，已有记录仍可查看和完成必要处理；
- Windows小窗口下主要页面无严重遮挡和操作按钮丢失；
- 视频、图片引用、群历史消息和会话置顶功能正常；
- 验收版本无本次改动造成的阻断性崩溃、无法登录或数据串号。
