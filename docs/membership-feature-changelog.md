## 二、前端新增/补强功能详细列表

# 1. 套餐排序与默认选中策略优化

## 1.1 新增套餐优先级排序
新增了套餐排序逻辑，用于让购买页优先展示更值得主推的方案。

排序依据包括：
- 年费优先于季费
- 季费优先于其他套餐
- 节省金额更高的优先
- 时长更长的优先
- 最后按价格排序

对应能力：
- `_orderedPlans(...)`
- `_defaultPlan(...)`

## 1.2 默认自动选中主推套餐
进入会员页时，不再随机或依赖后端顺序选择套餐，而是：
- 按排序结果自动选中第一页最优套餐

带来的效果：
- 打开页面就有明确推荐路径
- CTA、Hero、摘要区默认围绕主推方案展开

---

# 2. 套餐主推策略与营销文案增强

## 2.1 新增套餐营销标签策略
套餐卡不再只显示后端原始标签，而是根据套餐类型和排序结果动态生成营销标签。

示例：
- `主推 · 最划算`
- `主推推荐`
- `最划算`
- `灵活升级`

对应能力：
- `_planMarketingLabel(...)`

## 2.2 新增套餐支持性说明文案
为不同套餐类型补了更贴近购买决策的辅助说明。

示例：
- 年费：`长期持有更省心，适合重度使用`
- 季费：`先升级体验，预算和权益更平衡`

对应能力：
- `_planSupportCopy(...)`

## 2.3 新增节省金额和日均价格展示
套餐卡新增了更利于决策的信息层：
- 日均价格
- 原价删除线
- 立省金额

对应能力：
- `_dailyPrice(...)`
- `_saveAmount(...)`

# 3. Hero 顶部会员信息区联动增强

## 3.1 新增 Hero 标题联动逻辑
顶部 Hero 标题会根据当前会员状态和所选套餐动态变化。

已支持场景：
- 未开通
- 已开通
- 已过期
- 已停用
- 年费导向
- 季费导向

对应能力：
- `_heroTitle(...)`

## 3.2 新增 Hero 副标题联动逻辑
副标题会根据状态显示：
- 当前有效期
- 已到期提醒
- 停用恢复提示
- 年费/季费的购买建议

对应能力：
- `_heroSubtitle(...)`

## 3.3 新增 Hero 权益高亮联动
Hero 区的权益标签会随当前状态/套餐变化，强化首屏价值传达。

对应能力：
- `_heroHighlights(...)`

# 7. CTA 按钮区联动增强

## 7.1 CTA 文案按状态变化
底部 CTA 已支持按状态切换：
- 已开通：`已开通 xxx`
- 已过期：`立即续费 xxx`
- 已停用：`重新开通 xxx`
- 未开通：`立即开通 xxx`

对应能力：

## 7.2 已开通状态不再只显示禁用按钮
之前已开通时只是把购买按钮禁用。

现在改成：
- 直接显示“当前会员已生效”状态卡
- 展示有效期或已生效提示
- 明确告诉用户当前无需重复购买

## 7.3 非有效会员继续保留购买按钮
以下状态仍显示可操作 CTA：
- 未开通
- 已过期
- 已停用

## 7.4 底部脚注按状态变化
底部辅助提示已支持按状态联动：
- 续费恢复权益说明
- 重新开通恢复权益说明
- 默认即时生效说明

对应能力：
- `_statusFootnote(...)`

# 9. 异常态与空态收口

## 9.1 新增加载错误状态字段
页面新增：
- `_loadError`

用于区分：
- 加载中
- 正常内容
- 加载失败

## 9.2 `_load()` 新增失败处理
当接口失败或抛异常时：
- 清空页面数据
- 清空选中套餐
- 设置错误信息
- 页面切换为失败态

## 9.3 新增加载失败卡片
加载失败时，页面不再继续渲染正常内容，而是展示：
- `会员页加载失败`
- 错误文案
- `重新加载` 按钮

## 9.4 新增套餐为空状态卡片
当 `plans` 为空时，新增空态展示：
- `当前暂无可购买套餐`
- 套餐配置中的说明文案

## 9.5 空态时不再渲染购买区
无套餐时，隐藏：
- 套餐选择区
- 底部购买 CTA 区

从而避免“没有套餐但还给购买按钮”的不一致体验。
